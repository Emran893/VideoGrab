# VideoGrab - वीडियो डाउनलोडर (अपडेटेड वर्जन v2)

किसी भी वेबसाइट से बिना वॉटरमार्क के वीडियो डाउनलोड करने का वेब ऐप।

## नए अपडेट में क्या खास है?

✅ **YouTube Bot डिटेक्शन फिक्स** - Android क्लाइंट का उपयोग करके "Sign in to confirm you're not a bot" एरर हल
✅ **Gunicorn कॉन्फिग फिक्स** - `application = app` वेरिएबल जोड़ा गया
✅ **बेहतर एरर हैंडलिंग** - हर एरर के लिए यूजर-फ्रेंडली मैसेज
✅ **सभी साइटों के लिए बेहतर हेडर** - TikTok, Instagram, Facebook
✅ **Improved फ्रंटएंड** - बेहतर एरर डिस्प्ले, थंबनेल फॉलबैक
✅ **हेल्थ चेक एंडपॉइंट** - `/api/health`

## विशेषताएं
- 1000+ साइटें सपोर्ट (YouTube, TikTok, Instagram, Facebook, Twitter/X, Vimeo आदि)
- बिना वॉटरमार्क डाउनलोड
- सभी क्वालिटी ऑप्शन (144p से 4K तक)
- ऑडियो MP3 में भी डाउनलोड
- जवाबदेह (Responsive) डिज़ाइन
- बेहतर एरर हैंडलिंग

## लोकली चलाने के लिए

```bash
pip install -r requirements.txt
python app.py
```

फिर ब्राउज़र में खोलें: `http://localhost:5000`

## Render.com पर होस्ट करने के लिए (मुफ्त)

1. GitHub पर रिपॉजिटरी बनाएं और **सभी फ़ाइलें रुट में** अपलोड करें
   (न कि `web-version` फोल्डर के अंदर)

2. **सही फोल्डर स्ट्रक्चर:**
   ```
   आपकी_रिपॉजिटरी/
   ├── app.py
   ├── requirements.txt
   ├── render.yaml
   ├── vercel.json
   ├── README.md
   └── templates/
       └── index.html
   ```

3. render.com पर जाएं → New → Web Service
4. अपनी रिपॉजिटरी चुनें
5. सेटिंग्स:
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `gunicorn app:app`
6. Environment Variable: `PORT` = `10000`
7. Create Web Service

## महत्वपूर्ण नोट्स

### YouTube Bot डिटेक्शन के बारे में:
- हमने Android क्लाइंट का उपयोग करके इसे बाईपास करने का प्रयास किया है
- फिर भी कभी-कभी YouTube कड़ी सुरक्षा कर सकता है
- **समाधान**: कुछ देर बाद फिर प्रयास करें, या कोई दूसरा वीडियो आज़माएं
- **लोकली चलाने पर** यह एरर बहुत कम आता है

### ffmpeg की आवश्यकता:
- 1080p+ क्वालिटी के वीडियो को merge करने के लिए ffmpeg चाहिए
- Render.com पर अक्सर पहले से ही इंस्टॉल रहता है
