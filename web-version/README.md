# वीडियो डाउनलोडर - वेब वर्जन

किसी भी वेबसाइट से बिना वॉटरमार्क के वीडियो डाउनलोड करने का वेब ऐप।

## विशेषताएं
- 1000+ साइटें सपोर्ट करता है (TikTok, Instagram, YouTube, Facebook आदि)
- बिना वॉटरमार्क डाउनलोड
- सभी क्वालिटी ऑप्शन (144p से 4K तक)
- ऑडियो MP3 में भी डाउनलोड कर सकते हैं
- जवाबदेह (Responsive) डिज़ाइन - मोबाइल पर भी चलेगा

## लोकली चलाने के लिए

```bash
pip install -r requirements.txt
python app.py
```

फिर ब्राउज़र में खोलें: `http://localhost:5000`

## Render.com पर होस्ट करने के लिए (मुफ्त)

1. GitHub पर रिपॉजिटरी बनाएं और सभी फ़ाइलें अपलोड करें
2. render.com पर जाएं और साइन अप करें
3. **New +** → **Web Service** चुनें
4. अपनी रिपॉजिटरी चुनें
5. सेटिंग्स:
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `gunicorn app:app`
6. Environment Variable जोड़ें: `PORT` = `10000`
7. **Create Web Service** पर क्लिक करें

## Vercel पर होस्ट करने के लिए

1. GitHub पर रिपॉजिटरी बनाएं
2. vercel.com पर जाएं और अपनी रिपॉजिटरी इम्पोर्ट करें
3. `vercel.json` फ़ाइल पहले से ही कॉन्फिगर्ड है
4. डिप्लॉय पर क्लिक करें

## नोट: ffmpeg की आवश्यकता

कुछ हाई-क्वालिटी वीडियो (1080p+) के लिए वीडियो और ऑडियो अलग-अलग होते हैं जिन्हें merge करने के लिए `ffmpeg` की आवश्यकता होती है।

- **Render.com**: अक्सर पहले से ही इंस्टॉल रहता है
- **लोकल**: `sudo apt install ffmpeg` (Linux) या ऑफिशियल साइट से डाउनलोड करें
